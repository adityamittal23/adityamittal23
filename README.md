### 🧠 Adaptive RAG for Enterprise Knowledge Systems

**AI • RAG • Information Retrieval • NLP**

An adaptive retrieval system that dynamically selects retrieval strategies based on query complexity.

* 🔹 Query complexity analysis using a hierarchical fuzzy inference engine
* 🔹 Dense, hybrid BM25 + dense retrieval strategies
* 🔹 Cross-encoder reranking for complex queries
* 🔹 Designed for enterprise knowledge retrieval
* 🔹 Evaluated using benchmark datasets
